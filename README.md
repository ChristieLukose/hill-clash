# Hill Clash 🚛
A colorful 3D multiplayer truck hill-climbing game prototype.


## Tech stack
- React + TypeScript + Vite
- Three.js via React Three Fiber
- Rapier physics integration
- Socket.io planned for online multiplayer

## Run locally
```bash
npm install
npm run dev
```

## Current prototype
- 3D scene and terrain preview
- Truck model blockout
- Main menu UI
- Solo and split-screen preview entry points

## Roadmap
1. Vehicle controller and slope-aware climbing physics
2. Wheel/suspension/traction simulation
3. Local split-screen with independent player controls
4. Hill obstacles, checkpoints, finish logic
5. Garage, upgrades, truck skins and rewards
6. Online rooms and server-authoritative multiplayer
